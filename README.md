# monogram
README: This program first outputs a white S, pauses for a second and clears the hat,
outputs a white plus sign, pauses for a second and clears the hat, then outputs a 
green clover shape, pauses for a second and clears the hat for a final time. To 
compile this program, run "cc -o sshafi sigma.c -L ~/lib -I ~/include -lsense" on your
terminal, and then run "./sshafi".
